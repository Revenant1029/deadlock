What This Site Is

This site catalogues the heroes of Deadlock, Valve's third-person hero shooter. Each hero page documents a hero's vitality stats, weapon details, abilities, and lore in a consistent format. The roster on the Heroes page lets you browse every hero we've covered and jump straight to the details that interest you.

How It Was Built

The site is built with three core web technologies:

  • HTML — every page uses semantic structure: headers, navigation, main content sections, articles for hero cards, and footers.
  • CSS — a single external stylesheet controls the layout, typography, colour scheme, and responsive behaviour across all pages.
  • JavaScript — a small script powers the hero role filter on the Heroes page.

No frameworks, no build tools, no backend — just hand-written files you can open directly in a browser.
